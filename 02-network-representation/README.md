# 1.5.5 Packet Tracer - Network Representation

## Overview
This lab explores a network topology in Cisco Packet Tracer and introduces common network devices, connections, LANs, and WANs.

## Objectives
- Identify common network components.
- Understand the purpose of network devices.
- Compare LANs and WANs.
- Explore network media and connectivity.

## Tools
- Cisco Packet Tracer

## Files
- `network-representation.pka`: Original Packet Tracer activity.
- `network-representation.pkt`: Saved network topology, if verified to belong to this lab.
- `screenshots/`: Screenshots documenting the lab.

## Learning Outcomes
- Recognize end devices and intermediary devices.
- Understand basic network topology.
- Identify differences between LAN and WAN.
- Become familiar with network representation in Packet Tracer.

## Status
Practical activity completed by the learner. The saved topology and assessment results should be verified in Packet Tracer before claiming full completion.
